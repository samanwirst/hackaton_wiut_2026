WIUT Hackathon 2026 · Computer Vision track

Every traffic event on one camera, as a time segment — and an alarm before the crash.

A detector, a tracker and fourteen explainable rules turn a fixed CCTV view into labelled events; a causal risk model watches for conflicts frame by frame.

Problem and approach

Part A returns [start_sec, end_sec, label] for 14 event classes; Part B returns, at every frame, the probability that an accident starts within 5 s using only past frames.
