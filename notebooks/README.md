# Evidence audit

[`evidence_audit.ipynb`](evidence_audit.ipynb) checks the recorded original-sample
runs and the scoped signal-reader review. It recomputes segment counts, per-frame
risk coverage, runtime denominators, exact repeat equality and lamp agreement.
It does not run inference or measure event F1, hidden-test accuracy or calibrated
accident probabilities.

From the repository root, using Python 3.11:

```bash
python -m venv .venv-notebooks
.venv-notebooks/bin/python -m pip install -r requirements/notebooks.txt
.venv-notebooks/bin/jupyter-execute notebooks/evidence_audit.ipynb --inplace --timeout=120
```

The committed evidence files, official evaluator, source, configuration and weights
are required. Original video files are not: the notebook compares their recorded
SHA-256 identities rather than rehashing the videos. To regenerate the lamp review
itself, the four originals and the ordinary CPU environment are required:

```bash
python tools/review_signals.py --videos data/samples --out reports/scene_review
```

The notebook checks the model revision frozen in
`reports/original_gpu/calibrated/frozen.json`. A later model change should fail that
check until new run evidence is generated; do not silence the assertion or edit
saved output numbers to make a changed model appear verified.

The GitHub Tests workflow also executes the notebook top-to-bottom. Saved outputs
were generated by a real clean-kernel execution, not typed into the tables.
